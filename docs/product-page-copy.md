## 產品描述

### 問題

你訂閱了 20 個 RSS 來源。每天早上打開，100 則未篩選的標題。

你全部略過。三天後，你根本不再打開。

### 解法

**Daily Brief 用關鍵字把 100 則變成 8 則。**

設定一次，每天早上收到一份純文字簡報 —— 只有你關鍵字命中的內容，按你的分類分好，Email 或 Telegram 推播。

### 三分鐘上手

```bash
python3 daily_brief.py --init      # 產生設定檔
# 編輯 config/config.toml 填入關鍵字與來源
python3 daily_brief.py --send telegram
```

就這樣。沒有帳號、沒有註冊、沒有月費。

### 為什麼不用 AI

這個工具故意不使用 LLM。

關鍵字比對、URL 去重、時間窗控制 —— 這些都不需要推理。加進 LLM 只會增加成本、讓輸出每次措辭不一樣，而簡報最需要的是**可預測**。

零 API 成本。永久免費使用。輸出每次一模一樣。

### 特色

✓ 關鍵字過濾 — 只收你真正關心的
✓ 跨來源去重 — 同一篇轉載只出現一次
✓ 自訂分類軸 — 按你的關心方式分組
✓ 純文字輸出 — Email 與 Telegram 完美適配
✓ 零第三方依賴 — 只用 Python 標準庫
✓ 單一來源失敗不影響其他 — 不會因為一個網站掛了就整天沒簡報

### 系統需求

Python 3.11 以上。不需要 pip install。

### 常見問題

**Q: 跟 Feedly / Inoreader 有什麼不同？**
那些是月費制、要註冊、有帳號管理。你這個是一次買斷、跑在自己機器上、資料不出你的電腦。

**Q: 會不會需要一直維護？**
RSS 格式十三年來沒變。偶爾有來源改網址，改一行設定就好。程式本身不會壞。

**Q: 可以加多少來源？**
沒有上限。實測 20+ 個來源穩定運行。

## 常見異議處理

**「我可以自己寫」**
可以，上面有完整邏輯。但你得處理 retry、去重、時間窗、容錯。這些寫完要一兩天。

**「免費版不夠嗎」**
Feedly 免費版 100 源、Inoreader 150 源，但它們有月費、有帳號、資料在他們手上。這個是買斷、跑你自己機器。

**「會不會壞」**
RSS 格式穩定十三年。單一來源掛掉不影響其他來源，這點我們實測過。
